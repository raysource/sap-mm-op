MM（Materials Management，物料管理）是 SAP 里管「买什么、买多少、什么时候到、到了记在哪、钱怎么记」的那套东西。它一头连着采购业务（申请、订单、收货），一头连着财务会计（库存、暂估、应付），中间靠物料主数据和组织结构撑着。

一、MM 的四块业务

业务块在做什么典型事务码产生的凭证
物料主数据给每个物料建「身份证」：类型、单位、采购组、MRP、评估类、价格MM01 / MM02 / MM03无（主数据变更留变更凭证）
采购申请 → 询价报价 → 订单 → 合同/计划协议ME51N / ME21N / ME41 / ME31K采购订单（不产生会计凭证）
库存管理收货、发货、转储、盘点、退库MIGO / MB1B / MI01物料凭证（+ 会计凭证，涉及金额时）
发票校验（IV）把供应商发票与订单、收货做三单匹配，差异按容差处理MIRO / MIR4 / MRBR发票凭证 + 会计凭证
需求计划（MRP）按需求、库存、安全库存算出净需求，生成采购申请MD01 / MD02 / MD04采购申请

三、三张主数据，支撑整条链

主数据事务码关键内容层级缺了会怎样
物料主数据MM01物料类型 ROH、基本单位 PC、采购组、MRP 类型/批量、评估类 3000、价格控制 S、标准价 720.00客户端层（基本数据）+ 工厂层 + 存储地点层 + 评估层PO 里根本选不到这个物料，报「物料未在工厂中维护」
供应商主数据BP（旧 XK01）名称、采购组织下的货币/付款条件、公司代码下的对账科目 160000一般数据 + 公司代码层 + 采购组织层报「供应商未在采购组织 1710 中维护」
采购信息记录ME11供应商 + 物料 + 采购组织 → 净价 720.00、价格单位 1、计划交货 5 天供应商 + 物料 + 采购组织PO 报「无法确定净价」，只能手工填价（实际项目里不允许）
最常见的三个顺序错误① 先建 PO 再建供应商 → 供应商选不到；② 物料只建了「基本数据」，没建「采购」视图 → PO 行项目选不出；③ 信息记录漏了采购组织 → 价格带不出来。这三个错误在引导实操里都会真实报出来。

五、移动类型：库存动作的编码

移动类型（Movement Type）决定三件事：库存是加还是减、会不会产生会计凭证、对方科目是谁。

移动类型含义库存会计凭证典型场景
101采购订单收货+库存 Dr / GR/IR Cr供应商送货到厂
102收货冲销−反向收错货、退回
122退货给供应商（参照 PO）−GR/IR Dr / 库存 Cr来料不合格退回
501无采购订单收货+库存 Dr / 消耗 Cr零星采购、无 PO 的到货
561期初库存导入+库存 Dr / 期初 Cr上线时把旧库存录进来
311库位间转储（同工厂）此减彼增不产生主仓 → 线边仓
301工厂间转储此减彼增评估价不同才产生1710 → 1711
261发料到生产订单−消耗 Dr / 库存 Cr领料上线
201发料到成本中心−费用 Dr / 库存 Cr部门领用
101 和 501 的区别两者都让库存增加，区别在「有没有采购订单」：101 必须参照采购订单，金额按订单净价，对方科目是 GR/IR；501 不参照订单，金额按物料标准价，对方科目直接进消耗（费用）。所以 501 不会产生 GR/IR 余额，也无法在发票校验里匹配 —— 这类到货后续要么走费用，要么补一份订单再冲回。

六、会计：为什么会有 GR/IR 这个科目

现实里「货到」和「票到」总是不同步。SAP 用 GR/IR（Goods Receipt / Invoice Receipt，暂估应计）科目把这段时间差记下来：收货时先承认一笔「欠着但还没收到发票」的负债，等发票到了再转成真正的应付账款。

时点凭证借方贷方金额GR/IR 余额
收货 300 PC物料凭证 4900000001 + 会计凭证 5100000001140000 库存商品（原材料）191100 GR/IR 暂估应计216,000.00216,000.00（贷）
收到发票发票凭证 5105600001 + 会计凭证 5100000002191100 GR/IR 暂估应计160000 应付账款-供应商216,000.000.00
付款会计凭证 5100000003（F-53）160000 应付账款-供应商100000 银行存款216,000.000.00
三个判断① 只收货没发票 → GR/IR 是贷方余额（暂估负债）；② 先开票后收货（要关掉「基于收货的 IV」）→ GR/IR 是借方余额（预付）；③ 月结时长期不平的 GR/IR，用 MB5S 看明细，必要时 MR11 做重分类清理。

七、自动记账（OBYC）：科目不是手填的

库存相关凭证的科目由系统按「业务事务键 + 评估类 + 科目修改码」自动确定，配置在 OBYC。所以物料主数据里那个「评估类 3000」不是备注，它直接决定了这笔货记到哪个存货科目。

事务键用途本课取值示例
BSX库存过账（存货科目）评估类 3000 → 140000 库存商品-原材料
WRXGR/IR 暂估科目191100 GR/IR 暂估应计
PRD价格差异（标准价与实价不同）660200 采购价格差异
GBB冲销/消耗类（VBR = 生产消耗、VAX/VAY = 费用）410101 生产成本-原材料消耗
UMB评估类之间的差异（转储）按需配置
看凭证最快的方式任何过账后记下会计凭证号，用 FB03 打开：行项目里有 PK（过账码，40=借 / 50=贷）、科目、借贷方、金额。新手最大的进步，就是从「我点了什么」变成「账上多了哪几行」。

八、基础设置：新系统上线前必须点一遍的十项

业务用户平时碰不到配置，但「为什么我的单建不出来」十次有八次是这里少了一项。下面这十项按上线顺序排，前四项是组织，中间四项是计划与收货，最后两项是会计接口。每一项都标了 IMG 路径和你该问谁。

九、常见误解（先破掉再往下学）

  • 「采购订单过账了就占库存」：不对。PO 不动库存，只有收货（101）才动库存。
  • 「发票校验就是把发票录进去」：不对。它做的是三单匹配（订单 / 收货 / 发票），数量和金额都要对得上，差异按容差走。
  • 「库存金额 = 数量 × 订单价」：只在标准价物料且发票价格未变时成立。移动平均价物料每笔收货都会重算单价。
  • 「转储会影响利润」：311 同厂转储不动金额，也不产生会计凭证；只有跨评估范围（301）且价格不同才会产生差异科目。
  • 「删掉收货就能当没发生」：不能删，只能冲销（102 或 122）；已开票的还要先冲发票（MR8M）。
