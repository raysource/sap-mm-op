A. 组织结构：公司代码 · 工厂 · 采购组织（10 题）

  • 公司代码 = 对外出报表的法人；工厂 = 收货、库存、MRP、评估的场所；库存地点只是厂内位置。
  • 采购组织负责与供应商谈条件，一个工厂可以有多个采购组织，但只能指定一个「标准采购组织」。
  • 一个工厂只能属于一个公司代码；采购组织可以跨公司代码服务多个工厂。

Q1. 公司代码（BUKRS）在 MM 里最核心的作用是什么？

公司代码是出具资产负债表与损益表的法人单位，会计科目、记账期间、货币都在这一层。工厂决定库存与评估。

Q2. 库存数量在哪一层管理？

库存按「物料 + 工厂 + 库存地点」管理；MARD 表存的就是工厂/库位级库存。公司代码与采购组织都不直接管数量。

Q3. 「采购组织」的职责是？

采购组织是采购条件的谈判主体，供应商的采购数据、采购凭证号段都挂在采购组织下。价格评估是工厂/公司代码层的事。

Q4. 采购组（EKGRP）与采购组织的区别是？

采购组只回答「这单归谁跟」，不进入会计；采购组织才是条件谈判主体。

Q5. 一个工厂是否可以分配给多个采购组织？

工厂可被多个采购组织采购，通过「给工厂分配标准采购组织」指定默认值；无 PO 收货自动建单就依赖这一项。

Q6. 「评估级别」决定什么？

评估级别是集团级设置，常见为「在工厂级评估」——所以同一物料在不同工厂可以有不同的标准价。

Q7. 一个工厂可以属于两个公司代码吗？

工厂与公司代码是多对一：工厂归属唯一，公司代码可以有多个工厂。

Q8. 采购组织与公司代码的关系是？

采购组织可以跨公司代码集中采购，这是集团采购的常见做法；但会计上仍落在各公司代码。

Q9. 库存地点（LGORT）会影响采购价格吗？

库位只解决「货在厂里哪个位置」，不影响估价、不影响科目。

Q10. 物料在哪里做 MRP 运算？

MRP 在工厂层运行，工厂参数（MRP 组、计划边际码、收货天数）都在工厂/工厂参数里维护。

B. 物料主数据：类型 · 视图 · 表（12 题）

  • 物料类型（ROH/FERT/HALB…）决定可用视图、编号范围、是否强制估价、字段状态。
  • MARA 一般数据、MARC 工厂数据、MARD 库位库存、MBEW 估价数据、MARD 与 MARC 都按工厂展开。
  • 基本计量单位用于库存管理；订单单位用于采购；两者可以不同，系统按换算关系折算。

Q1. 物料类型主要不决定下面哪一项？

供应商对账科目在供应商主数据（公司代码层），与物料类型无关。物料类型决定视图、编号范围、评估控制与字段选择。

Q2. ROH / HALB / FERT 分别指？

ROH 原材料、HALB 半成品、FERT 成品；HAWA 是贸易商品，DIEN 是服务。

Q3. 物料的一般数据（描述、基本单位、物料组）存在哪张表？

MARA 是物料一般数据表；MARC 工厂数据、MARD 库位库存、MBEW 估价数据。

Q4. 工厂级的 MRP 类型、采购组存在哪张表？

MRP 类型、采购组、生产天数等都在 MARC（工厂级）。

Q5. 某个库位的非限制库存记录在哪张表？

MARD 存「物料 + 工厂 + 库位」的库存；MCHB 是批次库存，MSKA 是销售订单库存。

Q6. 标准价、移动平均价、评估类存在哪张表？

MBEW 是物料估价表，按评估区域（通常工厂）存价格控制、标准价、移动平均价、评估类。

Q7. 物料缺了「采购」视图，最直接的后果是？

缺采购视图 → PO 行项目无法带出采购组、订单单位等；收货与 MRP 分别看工厂/MRP 视图。

Q8. 物料缺了「会计」视图（未估价），最可能的报错是？

未估价就没有库存科目与价格，收货无法生成会计凭证。

Q9. 基本计量单位与订单单位的关系是？

库存按基本单位，采购可按订单单位（如箱、托），系统用换算关系折算。

Q10. 价格控制 S 与 V 的区别是？

S=标准价，收货价与标准价之差进价格差异；V=移动平均价，收货直接改变库存单价。

Q11. 物料主数据里「删除标记」与「删除」的区别是？

业务上常用「标记删除」阻止新单据引用；物理删除要走归档（MM74 等），不会一键删掉。

Q12. 物料组（MATKL）的作用更接近？

物料组用于采购分析/报表与部分科目确定，不直接决定数量或价格。

C. 供应商主数据与采购信息记录（10 题）

  • S/4HANA 供应商走 BP：角色 FLVN00（FI）+ FLVN01（MM），数据分地址 / 公司代码 / 采购组织三层。
  • 对账科目（如 160000）在公司代码层，填错会在发票过账时报科目确定失败。
  • 采购信息记录 = 供应商 + 物料 + 采购组织，PO 的净价优先从这里取。

Q1. S/4HANA 中维护供应商用哪个事务/对象？

S/4 用 BP 统一管理供应商与客户；XK01 已过时并会重定向到 BP。

Q2. BP 角色 FLVN01 代表？

FLVN00 是财务供应商，FLVN01 是采购供应商；采购组织数据挂在 FLVN01 下。

Q3. 供应商「三层数据」通常指？

地址层属于 BP 本身；公司代码层（对账科目、付款条件）；采购组织层（订单货币、采购组、两个开关）。

Q4. 供应商的对账科目填错，最先在哪一步报错？

对账科目属于公司代码层，与应付账款相关，通常在 MIRO 过账时因科目确定失败暴露。

Q5. 采购信息记录的键是？

信息记录按「供应商 / 物料 / 采购组织」维护，可再细化到工厂。

Q6. 建 PO 时净价的默认来源顺序，最优先的是？

先找信息记录（再找合同/计划协议），找不到才手工输入（若允许）。

Q7. PO 报「无法确定净价」，最可能的原因是？

净价来自信息记录；没有记录或价格为 0 就会报这条。

Q8. 「基于收货的 IV」在哪个事务里可以改？

信息记录里改（影响之后新建的 PO），已有 PO 用 ME22N 在行项目「发票」页取消。

Q9. 货源清单（Source List）的作用是？

货源清单是「合格供应商名单」，无 PO 收货自动建单要靠它找货源。

Q10. 供应商被「采购冻结」后，最直接的影响是？

采购冻结阻止新建采购凭证；已有单据与付款分别受中央冻结/付款冻结影响。

D. 采购凭证与流程：申请 → 订单 → 框架协议（12 题）

  • 采购申请是内部需求，不产生会计凭证；采购订单是对供应商的承诺，也不动库存与账。
  • 参照申请转单用 ME21N/ME57；订单类型 NB 标准、FO 框架、UB 库存转储。
  • 合同与计划协议是长期协议；询价/报价是 ME41/ME47/ME49 这一组。

Q1. 采购申请与采购订单最本质的区别是？

申请只是「谁要、要多少、何时要」；订单才对外承诺，且两者都不产生会计凭证。

Q2. 保存采购订单后，库存与会计账上发生了什么？

PO 只是凭证，不动物流也不动账；101 收货才增加库存并挂 GR/IR。

Q3. 参照采购申请转成订单，最常用的事务是？

ME21N 里填参照申请号回车即可带出；ME57 可批量分配与转单。

Q4. 订单类型 NB / FO / UB 分别表示？

NB 标准、FO 框架（合同/计划协议相关）、UB 库存转储订单；退货常用退货订单类型（如 RE）。

Q5. 采购订单的「释放策略」用在什么场景？

释放策略（Release Strategy）实现审批流：订单先建后批，未释放不能打印/收货。

Q6. 合同（Contract）与计划协议（Scheduling Agreement）的区别是？

合同约定总量与价格，用 ME21N 参照合同建调用单；计划协议直接排交货日程（ME38/ME84）。

Q7. 询价、报价、比价对应的事务码是？

ME41 询价、ME47 报价、ME49 比价；ME31K 建合同、ME31L 建计划协议。

Q8. 采购订单里「仍要交货」数量是怎么算的？

仍要交货 = 订单数量 − 已收货数量；「仍要开票」才是收货与开票的差额。

Q9. ME23N 里看「这单走到哪了」最直接的是哪个页签？

采购订单历史把创建 / 收货 / 发票 / 付款串成一条时间线。

Q10. 采购凭证的编号范围通常按什么分配？

编号范围挂在凭证类型上；不同订单类型可以走不同号段。

Q11. 采购订单能否直接引用合同而不引用申请？

合同/计划协议是长期协议，调用单直接参照合同即可，不需要先有申请。

Q12. MSR/退货场景下，退货订单与普通订单的主要区别是？

退货订单（如 RE 类型）用于把货退回供应商，收货时用 122 反向移动。

E. 收货 · 库存移动 · 盘点（12 题）

  • 101 订单收货、122 退货、102 冲销收货、311 库位转储（同价，无会计凭证）、301 工厂转储（可能产生凭证）。
  • 261 生产发料、201 成本中心发料、501 无 PO 收货、561 期初导入。
  • 库存变动一定伴随物料凭证；涉及金额时同时产生会计凭证。

Q1. 移动类型 101 的业务含义是？

101 是「收货到采购订单」，库存增加并挂 GR/IR。

Q2. 要把收到的货退回供应商，用哪个移动类型？

122 是退货交货（参照订单），库存减少、GR/IR 反向；102 只是冲销一次收货。

Q3. 102 与 122 的区别是？

102 冲销同一张收货凭证；122 是独立的退货业务，可参照订单做。

Q4. 库位之间转储（0001 → 0002）用什么移动类型？

311 只产生物料凭证、不产生会计凭证（同价转移）；301 是工厂间转储。

Q5. 哪种库存移动通常不产生会计凭证？

311 在同一工厂内同价转移，只有物料凭证；涉及跨工厂或价值变化才产生会计凭证。

Q6. 生产订单发料用哪个移动类型？

261 发料到订单/成本对象；201 是发到成本中心。

Q7. 发给成本中心（非生产订单）用哪个移动类型？

201 成本中心发料，费用进成本中心。

Q8. 501 与 101 的核心区别是？

501 是无采购订单收货，按物料价格进指定科目（常为消耗类），不生成 GR/IR。

Q9. 561 期初导入的正确用法是？

561 用于期初数据导入，通常伴随期初科目。

Q10. 盘点差异过账（MI07）会产生什么？

盘点差异按金额调整库存与损益，物料凭证与会计凭证都会生成。

Q11. 一张 101 收货通常会生成哪些凭证？

收货同时更新库存与 GR/IR 暂估，所以两张凭证都有。

Q12. 收货数量超过订单数量时的默认行为是？

收货容差（IMG 收货容差限制）默认允许超收一定比例，超出即报错。

F. 发票校验与 GR/IR（12 题）

  • 三单匹配：采购订单（应付多少）、收货（收到多少）、发票（要多少）。
  • 容差 OMR6：BD 小额差异、DQ 数量偏差、PP 价格变化、VP 移动平均价差异。
  • 超容差仍可过账但会冻结付款，用 MRBR 解除；GR/IR 的出口只有发票或 MR11。

Q1. 发票校验（MIRO）做的是什么？

MIRO 比对三单，把 GR/IR 暂估转为应付；付款是 F-53/F110。

Q2. GR/IR 暂估科目在什么时候被冲平？

收货挂 GR/IR 贷方，发票过账借方冲回；付款冲的是应付账款。

Q3. OMR6 里的 BD 容差指？

BD = 小额差异（Form small differences）；DQ 数量、PP 价格、VP 移动均价。

Q4. 发票金额超出订单净价 5%，最可能看到的处理是？

超出 PP 容差会触发价格检查（典型消息 M8083），发票被冻结，MRBR 释放后才能付款。

Q5. 释放冻结发票用哪个事务？

MRBR 释放冻结发票；MIR4 是显示，MIR7 是预制，MR8M 是冲销。

Q6. 预制发票（MIR7）与 MIRO 的区别是？

MIR7 保存为预置（Parked）凭证，过账仍要 MIRO 或后续处理。

Q7. 冲销一张已过账的发票用？

MR8M 冲销发票凭证，之后才能重开或退货。

Q8. GR/IR 余额为「贷方」通常说明？

收货已挂贷方而发票未到 → 贷方余额；票先到则是借方余额。

Q9. 发票的凭证类型 RE 与 RN 分别指？

RE 是发票（Gross），RN 是贷项凭证；金额为负时用贷项。

Q10. 「基于收货的 IV」未勾选时，可以？

未勾选时按订购数量带出，可以先票后货；勾选时必须有收货。

Q11. 后续借记（Subsequent Debit）的用途是？

后续借记是在原发票之后追加应付；后续贷记则相反。

Q12. 一张发票同时含有进货与退货，正确做法是？

同一发票内可混有借贷方向的行项目，必要时在「采购订单参考」旁的按钮里调整方向。

G. 估价与自动记账（OBYC）（10 题）

  • 标准价（S）：价格固定，差异进价格差异科目；移动平均价（V）：每次收货重算单价。
  • 自动记账按「事务键 + 评估类 + 评估分组」找科目：BSX 库存、WRX GR/IR、PRD 价格差异、GBB 发货消耗。
  • 评估类由物料主数据会计视图给出，决定这组科目；评估分组代码按工厂归组。

Q1. 价格控制为 S（标准价）时，收货价与标准价不一致的差额进哪？

标准价物料按标准价入库，差额进价格差异；这也是标准价能稳定成本的原因。

Q2. 价格控制为 V（移动平均价）时，发票差异通常？

移动平均价下差异进入库存价值，单价随之变化。

Q3. 自动记账里 WRX 事务键对应哪个科目？

WRX = GR/IR 清账科目；BSX = 库存，PRD = 价格差异，GBB = 发货/消耗。

Q4. BSX 事务键决定的是？

BSX 按评估类给出存货科目；不同评估类可以指向不同存货科目。

Q5. 收货过账报「科目确定失败」，最可能的原因是？

科目确定 = 事务键 + 评估类（+ 评估分组）在 OBYC 里找不到对应科目。

Q6. 评估类（BKLAS）在哪里维护？

物料的会计视图里填评估类，它决定用哪一组自动记账科目。

Q7. 评估分组代码（OBYC 里的 KALK）主要解决？

评估分组代码让你按工厂（或分组）细分科目；同评估类可挂不同科目组。

Q8. 标准价物料为何不适合频繁变价的原材料？

标准价把价格固定住，市价波动都进差异；是否适用取决于管理口径。

Q9. OBYC 配置属于哪个层面的工作？

OBYC 是自动记账配置，改一次影响所有相关过账。

Q10. 同一物料在工厂 A 用 S、工厂 B 用 V，可以吗？

价格控制在评估区域层，工厂级评估时不同工厂可各用 S 或 V。

H. MRP 与需求计划（10 题）

  • 净需求 = 需求 + 安全库存 − 可用库存 − 已订（在途）。
  • MRP 类型 PD 按需求计划、ND 不参与、VB 手动再订货点；批量 EX 精确、FX 固定、HB 补足上限。
  • MRP 运行生成采购申请（外购）或计划订单（自制），MD04 看单据链条。

Q1. MRP 净需求的基本公式是？

净需求把需求、安全库存、现有库存与在途订单放在一起算。

Q2. MRP 类型 PD 与 ND 的区别是？

PD 是常规 MRP，ND 完全不参与运算（用于手工管控物料）。

Q3. 批量 EX / FX / HB 分别指？

EX 精确按净需求，FX 固定批量，HB 补足到最大库存。

Q4. MRP 运行后，外购件通常生成？

MRP 生成采购申请或计划订单；转成 PO 才对外承诺（也可配置直接生成 PO）。

Q5. MD04 画面能看到什么？

MD04 是库存/需求清单，一张表看全计划相关要素。

Q6. 安全库存的作用是？

安全库存进入净需求公式，是缓冲量而非订单。

Q7. 计划边际码（Planning Time Fence）控制？

边际码保护近期计划不被 MRP 自动改动，避免频繁改单。

Q8. MRP 区域（MRP Area）用于？

MRP 区域可细化到库位/子工厂，实现更细的计划粒度。

Q9. 策略组 10 与 40 的典型区别是？

策略 10 是 MTS（按库存生产），40 是 MTO（按订单生产，销售订单直接产生需求）。

Q10. MRP 运行时「已订」指什么？

在途订单量要计入供给，否则会重复采购。

I. 特殊采购：寄售 · 委外 · 转储 · 框架协议（8 题）

  • 寄售：货在厂里但所有权属供应商，领用（K 类移动类型）才结算。
  • 委外加工（Subcontracting）：发组件给供应商，收货时按 BOM 反冲组件。
  • 转储：库存转储订单（UB）用于跨工厂；框架协议：合同 vs 计划协议。

Q1. 寄售库存（Consignment）的特点？

寄售库存物理上在你厂里，账上属于供应商；用 411/431 类移动类型领用并生成应付。

Q2. 委外加工收货时，系统对组件做什么？

委外 PO 带组件清单，收货（101）时组件按 BOM 消耗，成品入库。

Q3. 「统计物料」（Statistical Material）通常用于？

统计物料只记录数量用于分析，不进入库存价值；管道物料是典型场景。

Q4. 库存转储订单（UB）与库存转储（301）的区别是？

UB 用于需要正式单据的跨工厂转储（可含运输、计划），301 是直接过账。

Q5. 框架协议包括哪两类主要形式？

合同（ME31K）与计划协议（ME31L），后续分别用调用单/交货计划。

Q6. 批次管理与序列号管理的区别是？

批次按批次号追溯（效期、质量），序列号是单件唯一标识。

Q7. 第三方采购（Third-Party）的业务特点是？

第三方业务里货物流不经过你方仓库，只有单据流与结算流。

Q8. 寄售领用通常用哪类移动类型？

寄售领用用 411 K（从寄售库存转自有/消耗），与普通 101 不同。

J. 报表 · 事务码 · 权限与期间（10 题）

  • 查凭证 MB51、查库存 MB52/MMBE、查 GR/IR 用 MB5S、查物料清单 MM60、查采购订单 ME2L/ME2M。
  • 权限报错用 SU53 看缺哪个授权对象；个人参数用 SU3（LANG/WRK/BUKRS）。
  • 期间：会计期间 OB52、物料期间 MMRV/MMPV；两个都要开才能收货。

Q1. 要按条件查物料凭证清单，用哪个事务？

MB51 物料凭证清单（按物料/移动类型/期间）；MB52 是库存清单。

Q2. 看某个物料在各库位的库存，最方便的是？

MMBE 单物料总览，MB52 批量库存清单。

Q3. 月末核对 GR/IR 余额用哪个事务？

MB5S 按 PO 行列出收货/发票金额与余额，是 GR/IR 对账首选。

Q4. 按物料汇总采购订单，用哪个事务？

ME2M 按物料、ME2L 按供应商列采购订单。

Q5. 要列出某物料类型的所有物料，用？

MM60 是物料清单报表（按类型/工厂筛选）。

Q6. 直接看表 MARA/MARC 的数据，用哪个事务最方便？

SE16N 表浏览；SM30 维护配置视图，ST05 是 SQL 跟踪。

Q7. 报「没有授权执行事务 X」，第一步查什么？

SU53 显示最近一次权限检查失败的对象，交给 Basis/安全顾问加角色。

Q8. SU3 的作用是？

SU3 只影响个人默认值，不改系统配置，也不改别人的设置。

Q9. 月末收货报「过账期间未打开」，应检查？

收货同时写库存与会计，两个期间都必须包含当月。

Q10. 看某条状态栏消息的触发条件与处理办法，最规范的做法是？

按消息号查（如 M8083、M7021），能直接看到触发条件与建议处理。

K. 综合模拟卷（20 题）

下面的题不再按章节分组，全部是「现场遇到会怎么判」的类型：报错先查哪里、账上动了哪两行、这一步会不会产生凭证。

Q1. 新建了一个物料，采购订单里却选不到它，最可能缺哪个视图？

PO 行项目取采购组、订单单位等采购视图数据；缺采购视图就选不到或带不出数据。

Q2. 收货时提示「物料未在工厂 1710 中维护」，说明？

工厂视图（MARC）缺失时，系统认为该物料不存在于这个工厂。

Q3. 订单 4500000123 收货 300 PC 后，又收到 300 PC 的发票，此时 GR/IR 余额是？

收货挂贷方、发票冲借方，金额一致则归零。

Q4. 发票金额比收货多 0.5%，在默认容差内，结果是？

容差内允许过账，差额按 BD/PP 规则进差异科目，不阻塞付款。

Q5. 采购订单已全部开票后还要再开一张，应？

已开票数量占满后无法继续开票，冲销原发票才能重开。

Q6. 想要「先收货后开票」变成「先开票后收货」，应改哪里？

取消该勾选后，MIRO 可按订购数量开票；已有 PO 需 ME22N 逐单取消。

Q7. 无 PO 收货自动建单，不需要下面哪一项？

自动建单依据货源清单与信息记录，不要求先有申请。

Q8. 标准的库位转储（311）对会计的影响是？

同工厂同价转移，价值不变，所以没有会计凭证。

Q9. 生产发料（261）的会计分录通常是？

发料把材料成本转入生产订单/成本对象，库存减少。

Q10. 标准价物料的收货价高于标准价，差额进？

标准价把入库价值固定，差价进价格差异科目。

Q11. 下列哪个不是采购凭证？

物料凭证属于库存管理凭证；申请/订单/合同是采购凭证。

Q12. MRP 运行后生成的采购申请，其凭证号属于哪个号段？

按凭证类型分配的编号范围决定号段。

Q13. 安全库存从 20 提高到 120，其他不变，MRP 净需求会？

净需求 = 需求 + 安全库存 − 库存 − 在途，安全库存增加直接抬高净需求。

Q14. 供应商在采购组织 1710 下没有数据，建 PO 时会报？

供应商的采购组织层缺失，PO 无法带出订单货币/付款条件。

Q15. 下列哪个事务用于查看物料的变更历史？

MM04 显示物料主数据的变更凭证（谁、何时、改了哪个字段）。

Q16. 一张发票被冻结，付款时最可能看到？

冻结拦截付款，MRBR 释放后才可清账。

Q17. 月结时 GR/IR 仍有贷方余额，说明？

贷方余额=已收货未开票，月末需跟进发票或用 MR11 处理。

Q18. 若要限制某采购员只能处理自己采购组的订单，靠什么实现？

权限按采购组等字段做限制，属于角色设计。

Q19. 下列哪项会同时影响库存数量与会计金额？

101 增加库存并挂 GR/IR；311 只动库存位置；PO 保存不动账。

Q20. 同一物料在工厂 1710 用标准价、工厂 1720 用移动平均价，是否可行？

工厂级评估时，价格控制按工厂各自维护。
