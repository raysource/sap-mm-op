正常流程是「先下单、后收货」。但现实里总有人把货先送来：口头订货、紧急补料、供应商主动发货。这时仓库如果只会说「没有订单不能收」，货就压在门口。SAP 的解法是让移动类型 101 自己产生采购订单——前提是四处开关都打开，缺一处就退回手工输入订单号。

一、机制：收货时反查货源，自动补 PO

在 MB01（货物移动）里选移动类型 101、填物料/工厂/数量/供应商，采购订单字段留空。系统这时按下面的顺序找货源：物料主数据的采购视图 → 工厂的货源清单 → 信息记录的价格。三样都在、且四个「允许自动建单」的开关都打开，系统就生成一张采购订单，再拿它做收货过账，状态栏会同时给出物料凭证号和自动生成的采购订单号。

MB01收货 101不输 PO→自动生成 PO按货源清单 + 信息记录→物料凭证49xxxxxx 库存 +→FB03会计凭证库存 Dr / GR/IR Cr

二、六个前提（少一个就失败，按这个顺序配）

#在哪配做什么漏了会怎样
1IMG：物料管理 → 总量控制 → 收货 → 自动创建采购订单（或 OMJJ 移动类型）把 101 GR 收货的第三项「自动产生的采购订单」勾上MB01 报「请输入采购订单」，不会自动建单
2IMG：企业结构 → 分配 → 物料管理 → 给工厂分配标准采购组织工厂 1710 必须有一个默认采购组织系统不知道用哪个采购组织建单，直接报错不建
3供应商主数据（XK02 / BP）采购数据 → 控制数据勾「自动产生的采购订单」提示「供应商未设置自动采购」
4IMG：物料管理 → 采购 → 货源清单 → 定义工厂层的货源清单需求在工厂 1710 那一行勾「货源清单」系统不去查货源清单，价格/供应商都带不出来
5ME01（货源清单）给 物料 + 工厂 维护可用供应商（可设固定货源）报「未找到有效货源」；实际测试里这条最关键
6MM02 → 采购视图勾「自动采购单」系统不认为这个物料可以自动建单
还有一个隐含前提信息记录（ME11）必须已存在且价格正确，否则自动建出来的 PO 没有净价，收货金额为 0，会计凭证也记不出数。文档里的原话是「完成了以上设置，在 MB01 做 101 收货时，当未输入采购订单时，系统将为你自动创建采购订单」——四处开关 + 货源清单 + 价格，一条都不能少。

三、执行：MB01 收货，不输订单号

  1. 命令字段输 MB01，回车。（8.10 里 MIGO 也能做，但「自动建 PO」这套配置多数教材用 MB01 演示，字段少、看得清。）MB01
  2. 移动类型填 101，回车；系统带出「收货采购订单」的默认画面。Enter
  3. 凭证日期保持今天（或本期间内），采购订单字段留空。Tab
  4. 物料 R-1002、工厂 1710、库存地点 0002、数量 50、供应商 100124。F4
  5. 回车检查：没有报错时，状态栏只显示「检查已通过」；点 ✓ 过账。Ctrl+S
  6. 记下两个号：物料凭证 4900000002、自动生成的采购订单 4500000124（号段取决于你先做过几张单据，按你自己屏幕上的为准）。—
  7. 用 ME23N 打开自动生成的 PO：行项目就是 R-1002 / 50 PC / 180.00 USD，净额 9,000.00 USD。ME23N

四、会计：自动建单不影响分录，只影响「有没有依据」

科目名称借方贷方说明
140100原材料（库存）9,000.0050 PC × 标准价 180.00，评估类 3000
191100GR/IR 暂估应计9,000.00货到票未到，挂暂估负债
合计9,000.009,000.00借贷平衡

自动建 PO 只解决「单据从哪来」，记账逻辑仍是标准收货：库存增加、GR/IR 挂账。等到 MIRO 收到发票，GR/IR 才被冲平、转为应付账款。若这张 PO 之后没有发票，GR/IR 就一直挂着——这正是月末 GR/IR 余额表（MB5S）要解释的东西。

五、会计期间：为什么「上个月的货这个月收不了」

收货会同时写物料账和会计账，所以两个期间都得打开：会计期间（OB52）和物料期间（MMRV/MMPV）。月末封账后忘了开新期，是新手最常撞的一堵墙，报错看起来和业务毫无关系。

对象事务码管什么典型报错
会计期间OB52按期间类型（K 供应商 / A 资产 / D 客户 / M 物料 / S 总账 / V 合同）打开 1～12 期与 13～16 调整期过账期间未打开 / 期间已关闭

物料期间MMRV / MMPV查看当前物料期间、是否允许记上一期；MMPV 逐期结转物料期间 11/2026 未打开
会计年度变式OB29决定一年有多少个记账期（常见 12 期 + 4 个特别期）期间号超出年度变式范围
两个期间的顺序先开物料期间，再开会计期间（或同时开）。只开会计不开物料，收货报「物料期间未打开」；反过来只开物料不开会计，报「过账期间未打开」。两个都关着时，报错先出会计那条，别以为物料没问题。

六、通过标准与常见报错

  • MB01 用 101、不填 PO、填 R-1002 / 1710 / 0002 / 50 / 100124，点 ✓ 后状态栏同时出现物料凭证号与 PO 号。
  • ME23N 能打开这张自动生成的 PO，行项目数量与净价正确（50 PC / 180.00 USD / 9,000.00 USD）。
  • MMBE 看 R-1002 在 0002 的库存从 20 变成 70 PC。
  • FB03 打开会计凭证：库存借 9,000.00、GR/IR 贷 9,000.00，借贷平衡。
  • 故意关掉物料层的「自动采购单」再收一次货：系统应报「请输入采购订单」，而不是默默生成。
  • 把 MMPV 结到下一期后再用本月日期收货：系统应报物料期间错误——这就是月末封账的典型症状。

什么时候不要用自动建 PO自动建单适合「零星、金额小、口头订货」的场景。它绕过了采购的审批与比价，金额大或需要合同、框架协议时，应当坚持「先建 PO 再收货」。很多公司干脆把 101 的自动建单关掉，改用 501（无采购订单收货）走费用化路径——两条路的差别是：101 自动建单仍然进库存、仍有 GR/IR；501 直接进费用，不进库存。
