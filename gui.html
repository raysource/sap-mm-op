SAP GUI 8.10 用 Horizon 主题：标题栏深蓝、菜单栏白底、系统信息挪到菜单栏右端、图标是细线风格。先把登录和五个区域认全，后面所有事务码的操作都是同一套动作：输事务码 → 回车 → 填字段 → 回车检查 → ✓ 保存。

一、登录：三个字段决定你进哪个系统

二、SAP Logon 8.10：登录之前先选系统

8.10 的入口叫 SAP Logon，它本身不是 SAP 画面，而是一个连接管理器：左边是你保存的连接，双击（或选中后点「登录」）才弹出真正的登录对话框。第一次用时需要「新建」一个连接，填系统 ID、实例号、消息服务器。

三、主题：8.10 长什么样，以及为什么公司里看着不一样

8.10 默认 Horizon 主题（Quartz 系列的继任者），另有 Morning / Evening 两个明暗变体。8.10 起还支持自定义主题：公司可以用 UI Theme Designer 做一套共用主题，或在 SAP GUI 选项里用 Quick Theming 只改 6 个主色，其余颜色由这 6 个算出来。

外观元素Horizon 下的样子和 7.70 / Quartz 的区别
标题栏深蓝底、白字，只有「‹ 返回 + 当前事务名 + 窗口按钮」7.70 是灰色 3D 渐变
菜单栏白底黑字，右端是系统信息（系统 · 客户端 · 语言 · INS/OVR）7.70 的系统信息在状态栏
工具栏白底、细线图标，命令字段为圆角输入框 + 右侧下拉箭头7.70 图标更粗、带立体边框
可编辑 / 只读字段可编辑白底带细边框，只读灰底无边框8.10 的区分更明显，表格里也一样
状态栏只剩消息与消息号；高度更矮7.70 还带系统信息与键盘状态
主题定制Quick Theming 改 6 个主色；或整包自定义主题7.70 只有固定几套
换主题不改操作本课所有截图、仿真器都按 Horizon 还原。如果公司用的是自定义色或 Morning 变体，颜色会变、按钮位置不变——所以下面这些「在哪输入、按什么键」的规则在任何主题下都成立。

四、主画面五区（SAP Easy Access）

五、命令字段：全站最重要的一格

写法含义什么时候用
MM03直接跳转（不带 /n）日常最常用；在当前事务里再开一个时会叠事务栈
/nMM03结束当前事务，再开 MM03卡在某个画面、想干净地重开时
/n只结束当前事务，回主画面相当于关掉当前单据（未保存内容丢失）
/oMM03新开一个窗口跑 MM03要对照两个画面看数据时
/i删除当前会话（session）会话开太多时
/nex结束当前事务并退出登录换用户/下班
两个坑① 命令字段里输的是「事务码」，不是菜单路径；输错会提示「事务码 XXX 不存在」，不影响已经录入的单据。② /n 会丢掉未保存的输入，填了一半别习惯性敲 /n，先 ✓ 保存或按 F3 返回。
8.10 起命令字段还能搜输入 *采购订单 或菜单名的一部分再回车，系统会列出匹配的事务码与菜单路径（事务搜索）。记住整串 T-code 之前，用它找比翻菜单快；但中文菜单名与英文 T-code 混搜时结果会变少，考试/实操还是背 T-code 最稳。

六、工具栏六个按钮（新手只要记这六个）

按钮名称快捷键作用
✓Enter / 回车Enter / F8触发检查、展开明细、确认弹窗；不是保存
◀返回 BackF3回上一层；有未保存内容时会问是否保存
💾（蓝色）保存 SaveCtrl+S真正写库并给单号；只有这一步才生成凭证
✕（红色）退出 ExitShift+F3退出当前事务，未保存内容丢失
🔍查找Ctrl+F在清单/表格里搜关键字
🖨打印Ctrl+P打印当前单据或清单
最常见的误会「我按了回车，为什么没保存？」——回车只做检查。SAP 里保存是 ✓ 或 Ctrl+S，状态栏出现「… 已保存 / 已过账」才算进库。

七、键盘：会用 Tab 和 F 键，速度快一倍

键作用为什么重要
Tab下一个字段字段之间移动用 Tab；回车（Enter / F8）会触发整屏校验，适合填完一段后检查，不适合串字段
Shift+Tab上一个字段改错上一个字段时
F4字段帮助（值列表）不知道工厂/物料组填什么时按 F4 选，比猜快
F1字段说明看不懂字段含义时按 F1，会带出技术信息（参数 ID、表名）
Ctrl+Y复制字段内容把光标放在字段里按 Ctrl+Y 可复制值
Ctrl+S保存等同 ✓
F12取消（Cancel）放弃当前画面输入，回到初始屏
F1 是被低估的功能F1 打开帮助后点「技术信息」，能看到字段所在的表（如 MARC、MARD）、字段名（如 WERKS、LGORT）和参数 ID。写文档、查配置、跟顾问沟通时，说得出的就是这些名字。

八、状态栏消息：三种颜色判断成败

图标类型例子怎么办
✓ 绿成功 / 已保存物料 R-1001 已创建记下单据号，继续下一步
! 黄警告（可继续）交货日期在过去；发票有差异已冻结看是否接受，必要时修正
✕ 红错误（拦住了）供应商 100123 未在采购组织 1710 中维护按提示补主数据或改字段，别硬保存
i 蓝信息输入后按 Enter 或点工具栏 ✓只是提示

状态栏里的消息号（如 M8083、M7021）可以直接搜：帮助 → 应用帮助 → 搜消息号，能看到触发条件和解决办法。

九、个人参数（SU3）与语言

  1. 输入事务码 SU3，进入「维护用户参数文件」。SU3
  2. 参数 ID LANG 设成 ZH / EN / JA：以后登录默认这个界面语言。
  3. 参数 ID WRK 设 1710：很多画面的「工厂」字段会自动带这个值。
  4. 参数 ID BUKRS 设 1710：公司代码默认值。
  5. 保存（✓）。下次登录生效；当前会话点「用户 → 参数」也能立刻应用。
别把默认值当配置SU3 只影响你自己看到的默认值，不改系统数据。别人登录还是空的；正式单据仍以填进去的值为准。

十、帮助与表格：F1 / F4 与 ALV 的键盘用法

动作按键 / 操作拿到什么
字段说明光标放字段里按 F1字段含义 + 技术信息（表名、字段名、参数 ID、数据元素）
值列表（帮助）光标放字段里按 F4可选值清单；清单上方还能按条件搜索
表格列选择点列标题右侧的小箭头排序、筛选、合计、列宽、导出到 Excel
表格单元格在 ALV 里按 F2 切换到单元格编辑多行文本、长数字不丢精度
导出清单 → 电子表格 / 本地文件ALV 可导出 xlsx / csv / 文本
收藏菜单 → 收藏夹 → 添加到收藏夹把常用 T-code 固定到主画面左侧
F1 里的「技术信息」是万能钥匙报错说「字段 XXX 未维护」时，先用 F1 → 技术信息确认这个字段属于哪张表、哪个参数 ID，再去 SU3 / SPRO 查。这一步能把「玄学报错」变成「某个配置项没设」。

十一、画面「点了没反应」时先查这四件事

  • 有没有弹窗被挡住：SAP 的确认框有时跑到窗口外面，看任务栏或按 Alt+F6 切回来。
  • 红色下划线的必填项：SAP 的必填是字段下红框/勾，不是星号；没填就会一直被打回。
  • 有没有点错按钮：回车 ≠ 保存；返回（F3）会问是否保存，选「否」就全丢。
  • 权限不足：报「没有 XXX 的授权」，用 SU53 看缺哪个授权对象，找 Basis 开权限。
