4. 三个字段为什么这么填

字段本课值为什么填错的后果
物料类型 ROHROH原材料：只买不卖，视图少、科目走存货选成 FERT 会多出销售视图要求，收货科目也可能不对
评估类 30003000（原材料）配合 OBYC 决定存货科目 140000 与 GR/IR 科目 191100收货直接报「科目确定失败」（M8 147）
价格控制 S + 标准价 720S / 720.00标准价物料：收货按 720 记库存，与订单价差额进价格差异选 V（移动平均）则每笔收货重算单价，教学上难对账
MRP 类型 PDPD按 MRP 运算生成采购申请选 ND 则永远不参与计划，MD04 跑不出需求
批量 EXEX精确按净需求下单选 FX 会按固定批量取整（如每次 100）
安全库存 2020 PC需求 400 + 安全 20 − 可用 300 = 净需求 120填太大虚增采购，填 0 会缺料

6. 供应商（BP）：三个页签、四层数据

S/4HANA 用 BP（Business Partner） 统一管理供应商与客户。同一个业务伙伴可以同时是「客户」和「供应商」，由角色决定能看到哪些数据：FLVN00 财务供应商（对账科目、付款条件）、FLVN01 采购供应商（采购组、订单货币）。界面上这些数据分成四个页签：地址 → 公司代码 → 采购组织 → 状态，顺序就是录入顺序。

  1. 业务伙伴填 100123，角色 FLVN01，分组 BP01，回车。Enter
  2. 弹出角色选择：FLVN00 与 FLVN01 都勾上（只勾 FLVN01 也能建，但发票会缺公司代码数据）。Space
  3. 「地址」页签：名称 1、城市、国家/地区（US）、语言 EN。这一层不分组织。Tab
  4. 「公司代码」页签：公司代码 1710、对账科目 160000、付款条件 0001、容差组留空。Tab
  5. 「采购组织」页签：采购组织 1710、采购组 001、订单货币 USD；无 PO 收货时才勾「自动产生的采购订单」。Tab
  6. 「状态」页签确认三个冻结都未勾，然后 ✓ 保存。Ctrl+S
字段所在层必填怎么填 / 填错的后果
业务伙伴编号一般是外部给号就自己输（100123…）；留空由系统给号，要看编号范围（BP01）
业务伙伴角色一般是FLVN00 + FLVN01 都勾；缺 FLVN01 → PO 选不到供应商
名称 1 / 城市 / 国家地址是发票、PO 打印都取这里；只改公司名不动这里，单据上还是旧名字
对账科目公司代码是160000（应付账款）；填错 → MIRO 报「科目确定失败」
付款条件公司代码是0001 立即付款（本课）；实际常 0002 = 14 天 2% 折扣
容差组公司代码否留空用默认；要放宽某供应商的发票容差才填
采购组织 / 采购组采购组织是1710 / 001；采购组决定这单归谁跟
订单货币采购组织是USD；与公司代码货币不同时 PO 会带汇率
自动产生的采购订单采购组织否只有「无 PO 收货」场景才勾（见第 5 章）
基于收货的 IV采购组织否默认勾；要「先开票后收货」就取消（见第 6 章）
三层数据，缺一层就开不了单一般数据（地址）→ 建得出 BP，但 PO 里选不到；+ 采购组织 → 能下单；+ 公司代码 → 发票才能过账。报错时先看它说的是哪一层：「未在采购组织 1710 中维护」= 缺采购组织层；「科目确定失败」= 公司代码层的对账科目有问题。

7. 采购信息记录（ME11）：价格从这来

8. 通过标准与常见报错

  • MM03 能查到 R-1001，五个页签都有值，标准价 720.00 USD
  • BP 里 100123 在采购组织 1710 下可见，对账科目 160000
  • ME11 记录 5300000123 净价 720.00、价格单位 1
  • ME21N 选供应商 100123 + 物料 R-1001 时，净价自动带出 720.00（无需手填）
状态栏原文根因先查哪里
物料 R-1001 已存在重复创建MM03 先查；改数据用 MM02
供应商 100123 未在采购组织 1710 中维护BP 只建了一般数据/公司代码层BP 里补「采购」页签，或 XK02
物料 R-1001 未在工厂 1710 中维护MM01 时工厂填错或没建工厂视图MM01 追加工厂视图（选视图时只勾工厂/存储）
无法确定净价：采购信息记录 100123 / R-1001 不存在漏建 ME11 或采购组织不符ME11 补建，核对组织 1710
输入的错误：评估类 3000 未定义（M8 147）评估类在 OBYC 未配置科目问 FI/顾问查 OBYC BSX/WRX
