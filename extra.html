主线走通之后，现场真正天天遇到的是这几类：没有采购订单就送到的货、来料不合格要退、仓间调拨、发票金额和收货对不上、月结时 GR/IR 挂着一堆余额。这一章把它们逐个拆开做一遍。

一、501 其它收货：和「101 自动建单」的区别

现实里总有零星到货：设备备件、样本、急件。没订单就不能做 101，用移动类型 501（无采购订单收货）：库存增加，金额按物料标准价，对方科目直接进消耗（费用），不产生 GR/IR，也不会出现在发票校验的三单匹配里。

移动类型什么时候用金额来源对方科目GR/IR
501无订单的零星到货、备件物料标准价（S）或移动平均价（V）消耗 / 费用科目（GBB-VBR 等）不涉及
561上线初始化库存（期初导入）物料标准价期初库存调整科目不涉及
101有订单的正常收货订单净价GR/IR 暂估挂负债
还有一条路：让系统自动补订单SAP 支持「无 PO 收货时自动生成采购订单」，但要同时满足 7 个前提：① 移动类型 101 勾了「自动产生的采购订单」（SPRO → 物料管理 → 总量控制 → 收货 → 自动创建采购订单）；② 工厂已分配标准采购组织；③ 供应商主数据勾了「自动产生的采购订单」；④ 工厂层启用了货源清单；⑤ 物料有货源清单记录；⑥ 物料采购视图勾了「自动采购单」；⑦ 信息记录价格正确。缺一条就会报「未找到有效货源」。练习里我们用 501，比配这 7 条更快。

二、退货：122 与 102 别用错

场景事务码 / 移动类型做什么会计影响
整批退给供应商（已收货、已开票前）MIGO，移动类型 122，参照 PO库存减少，GR/IR 反向冲回GR/IR Dr / 库存 Cr
只是收错、冲销收货MIGO，移动类型 102，参照物料凭证把 101 整笔冲掉库存 Cr / GR/IR Dr
已开票后要退先 MR8M 冲发票 → 再 122 → 再 ME22N 改单顺序不能反发票、库存、GR/IR 依次回退
顺序错了会卡住已开票的订单直接做 122，报「发票已存在，不能退货」。正确顺序：MR8M 冲销发票 → 122 退货 →（必要时）ME22N 调整订单数量。冲销类操作一律在引导实操里先冲后改，避免账实不符。

老的 MB1A（发货）、MB1B（转储）、MB1C（其它收货）在 S/4HANA 仍然可用，但官方推荐统一用 MIGO；批量导入（BDC/CATT）时反而常用老事务码，因为 MIGO 的画面元素更复杂。

四、发票差异与冻结：容差速查（详见 GR 与 IR 一章）

发票金额与收货金额不一致时，SAP 先做容差检查。容差按公司代码配在 OMR6，四类键最常用：

容差键检查什么本课设置超了会怎样
BD小额差异（发票总额与借贷差的绝对值）上限 50 USD在限内自动记入「小额差异」科目，发票仍可过账
DQ数量偏差（发票数量 vs 已收货/已订购）上限 1 PC 或 0.5%超了报数量差异，发票挂起
PP价格变化（发票单价 vs 订单净价）上限 1%超了报 M8083，直接拦住
VP移动平均价物料的价格差异上限 1%超了挂起，需人工处理差异科目
  1. MIR4 输入发票号：看净额、税额、总额、冻结状态与两行借贷。MIR4
  2. MRBR：列出所有冻结发票，逐张点「解冻」，或按供应商批量释放。
  3. F-53：解冻后才能付款；否则报「有冻结发票，请先在 MRBR 解冻」。
  4. MR8M：发票有错要冲销时用；冲销后才能重开票或退货。

六、MRP：净需求怎么算出来

MD04 把「需求、库存、在途」放在一条时间轴上。本课 R-1001：需求 400（生产订单 1000234，2026-11-18）+ 安全库存 20 − 可用 300 = 净需求 120 PC。可用库存按工厂合计（0001 + 0002 相加），所以做过 311 不影响；但如果先做过 261 领料 20 PC，可用变 280，净需求就是 140 —— MRP 永远按当时的实际库存算。

MRP 相关含义本课/常见值
MRP 类型是否参与计划、怎么算PD 按需求计划 / ND 不计划 / VB 手动再订货点
批量（Lot size）一次买多少EX 精确按净需求 / FX 固定批量 / HB 补足到上限
安全库存低于它就要补20 PC
MRP 控制者物料归哪个计划员001
MD01 / MD02 / MD04全厂运行 / 单物料运行 / 看结果练习用 MD04 里的按钮最直观
  • 无 PO 收货 501 后：R-1002 库存 20 → 50，GR/IR 余额不变
  • 退货 122 后：库存减少，GR/IR 反向冲回
  • 311 后：两库位合计不变，无新增会计凭证
  • 有差异发票：MIR4 状态为冻结，MRBR 解冻后 F-53 才能付款
  • MB5S 合计 0.00（P2P 走完）；有余额时能说清是哪张 PO
  • MD04 净需求 120，运行 MRP 后生成来源为 MRP 的采购申请
