SAP GUI 8.10 実践：まず画面に慣れ、次に 1 件の購買を自力で回す

このコースは 2 部構成です。前半は SAP GUI 8.10（Horizon テーマ）のログオン、5 つの領域、コマンドフィールド、ショートカット、ヘルプ機能を身体で覚えるまで練習します。後半は MM の業務に入り、品目マスタ → 購買依頼 → 購買発注 → 入庫 → 請求書照合 → 支払を、「PO なし入庫」と「GR/IR 照合」も含めて一通り実施します。

どの操作もページ内のシミュレータで実際に打ち込めます。トランザクションコードを入力して Enter、項目を埋めて ✓ で保存すれば、システムは伝票番号を採番し、エラーを返し、転記します。SAP のアカウントも仮想マシンも不要です。

始める前に、5 つの心得

  • Enter は保存ではありません：Enter はチェックと明細の展開だけを行います。実際にデータベースへ書き込み、番号を採番するのは ✓ か Ctrl+S です。
  • マスタが揃っていないと伝票は作れません：品目に購買ビューがなければ PO で選択できず、購買情報レコードがなければ PO は「正味価格を決定できません」で止まります。
  • 入庫と請求書は別のものです：入庫は品物を在庫に計上すると同時に GR/IR 仮勘定の負債を立て、請求書照合がその仮計上を買掛金に振り替えます。
  • 数量と金額は突き合わせる：入庫が 300 なら請求書も 300 でなければなりません。許容範囲（本コースは 1.000 %）を超える差額は M8083 のエラーになるか、請求書がブロックされます。
  • 在庫の変動には必ず伝票が伴う：品目伝票だけ（311 の同価格転送）か、品目伝票 + 会計伝票（101 / 261 / 501）のどちらかです。
