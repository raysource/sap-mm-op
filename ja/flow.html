この章が本線です。5 つのトランザクションコード、5 枚の伝票で、数量と金額が最後まで一貫します：300 PC × 720.00 = 216,000.00 USD。各ステップで「画面の再現 → 手順 → 重要項目 → ステータスバーに出るべき内容」を示します。終わったら ME23N の購買発注履歴ですべてつながります。

ステップ 2 ME21N：依頼 → 発注

PO を作っただけでは終わらない発注は保存後も「未承認」の状態で、入庫には影響しません（本コースでは解除方針を設定していません）。実際のプロジェクトでは、購買発注は承認（リリース）されて初めて入庫が許可されることが多く、ME29N や承認トランザクションで段階的に承認し、状態が「承認済み」に変わります。

ステップ 4 MIRO：3 伝票照合、仮計上を買掛金へ

金額を 1% 以上多く入れるとどうなるか219,000（216,000 の 1% 超）を入れる → ステータスバーに 価格が高すぎます（許容範囲 1.000 % を超過）— メッセージ M8083 と出て、請求書は転記できません。許容範囲は OMR6 で会社コードごとに設定します（BD 少額差異 / DQ 数量差異 / PP 価格変更 / VP 移動平均価格差）。わずかな差（≤ 1%）なら転記は許可され、差額は「少額差異」勘定に入り、請求書はブロックされます。支払には MRBR での解除が必要です。

  • 「購買発注履歴」タブに、登録済み／入庫 300／請求済み 300／支払済みの 3 行がそろっている

  • MB5S：この PO の GR/IR 残高が 0.00、合計 0.00
  • FB03 で 5100000001 と 5100000002 を開く：貸借それぞれ 216,000.00、勘定は上の表と一致
