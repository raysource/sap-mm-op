SAP GUI 8.10 は Horizon テーマです。タイトルバーは濃紺、メニューバーは白地、システム情報はメニューバーの右端に移り、アイコンは細線スタイルになりました。まずログオンと 5 つの領域を覚えてしまえば、以降のトランザクションはすべて同じ動作の繰り返しです：コードを入力 → Enter → 項目を入力 → Enter でチェック → ✓ で保存。

1. ログオン：3 つの項目で入るシステムが決まる

2. SAP Logon 8.10：ログオンの前にシステムを選ぶ

8.10 の入口は SAP Logon です。これ自体は SAP の画面ではなく接続マネージャで、左側に保存済みの接続が並びます。ダブルクリック（または選択して「ログオン」）して初めて、本来のログオンダイアログが開きます。初回は「新規」で接続を作成し、システム ID、インスタンス番号、メッセージサーバを入力します。

3. テーマ：8.10 の見た目と、社内で違って見える理由

8.10 の既定は Horizon テーマ（Quartz 系の後継）で、ほかに Morning / Evening の明暗 2 変種があります。8.10 からはカスタムテーマにも対応しました。企業が UI Theme Designer で共通テーマを作るか、SAP GUI のオプションで Quick Theming を使って 6 つの主色だけを変え、残りの色はその 6 色から算出します。

外観要素Horizon での見え方7.70 / Quartz との違い
タイトルバー濃紺地に白文字。「‹ 戻る + 現在のトランザクション名 + ウィンドウボタン」だけ7.70 はグレーの 3D グラデーション
メニューバー白地に黒文字。右端がシステム情報（システム・クライアント・言語・INS/OVR）7.70 のシステム情報はステータスバー
ツールバー白地に細線アイコン。コマンドフィールドは角丸の入力欄 + 右側のドロップダウン矢印7.70 はアイコンが太く立体的な枠付き
入力可 / 参照専用の項目入力可は白地に細い枠、参照専用はグレー地で枠なし8.10 のほうが区別がはっきりし、表の中でも同じです
ステータスバーメッセージとメッセージ番号だけ。高さも低くなりました7.70 はシステム情報とキーボード状態も表示
テーマのカスタマイズQuick Theming で 6 つの主色を変更、またはテーマ全体をカスタム7.70 は固定の数種類のみ
テーマを変えても操作は変わらない本コースの画面再現とシミュレータはすべて Horizon に合わせています。社内がカスタム色や Morning 変種でも、色は変わりますがボタンの位置は変わりません。つまり以下の「どこに入力し、どのキーを押すか」というルールは、どのテーマでも成り立ちます。

6. ツールバーの 6 つのボタン（初心者はこの 6 つだけで十分）

ボタン名称ショートカット役割
✓Enter / 改行Enter / F8チェックを実行し、明細を展開し、ダイアログを確定する。保存ではない
◀戻る BackF31 つ前の階層へ戻る。未保存があれば保存するか確認される
💾（青）保存 SaveCtrl+S実際にデータベースへ書き込み、伝票番号を採番する。伝票ができるのはこの操作だけ
✕（赤）終了 ExitShift+F3現在のトランザクションを終了。未保存の内容は失われる
🔍検索Ctrl+F一覧や表の中でキーワードを探す
🖨印刷Ctrl+P現在の伝票や一覧を印刷する
最も多い誤解「Enter を押したのに、なぜ保存されないのか」——Enter はチェックをするだけです。SAP の保存は ✓ か Ctrl+S で、ステータスバーに「… が保存されました / 転記されました」と出て初めて登録されます。

9. 個人設定（SU3）と言語

  1. トランザクションコード SU3 を入力し、「ユーザパラメータの保守」を開きます。SU3
  2. パラメータ ID LANG を ZH / EN / JA に設定：以降のログオン時の既定の画面言語になります。
  3. パラメータ ID WRK に 1710 を設定：多くの画面の「プラント」項目に自動で入ります。
  4. パラメータ ID BUKRS に 1710 を設定：会社コードの既定値になります。
  5. 保存（✓）。次回ログオンから有効です。現在のセッションでも「ユーザ → パラメータ」で即時反映できます。
既定値を設定と混同しないSU3 は自分が見る既定値にしか影響せず、システムのデータは変えません。他の人がログオンすれば空のままですし、正式な伝票では入力された値が優先されます。

11. 「クリックしても反応しない」ときにまず確認する 4 点

  • ダイアログが裏に隠れていないか：SAP の確認ダイアログはウィンドウの外に出ることがあります。タスクバーを見るか Alt+F6 で切り替えます。
  • 赤い下線の必須項目：SAP の必須はアスタリスクではなく、項目の下の赤枠やチェックで示されます。未入力なら何度でも差し戻されます。
  • ボタンを押し間違えていないか：Enter ≠ 保存。戻る（F3）は保存するか聞いてくるので、「いいえ」を選ぶとすべて失います。
  • 権限不足：「XXX の権限がありません」と出たら、SU53 で不足している権限オブジェクトを確認し、Basis 担当に権限を依頼します。
