5. Verifying the result: MM03, four tabs

6. Vendor (BP): three tabs, four data levels

S/4HANA keeps vendors and customers in one object, the business partner (BP). The same BP can be both a customer and a vendor; roles decide which data you see: FLVN00 (FI vendor: reconciliation account, payment terms) and FLVN01 (MM vendor: purchasing group, order currency). The screen splits that data into four tabs — Address → Company code → Purchasing → Status — which is also the entry order.

When something fails, first check which level the message names: “not maintained in purchasing org 1710” is the purchasing level, “account determination” is the company-code level.
